invora.
Your shop, on your Mac.

Inventory, invoices and LenDen with a native launcher. Requires Docker Desktop and macOS 14 or newer, subject to Docker’s current supported macOS versions.

  1. Install Docker Desktop for your Apple silicon or Intel Mac. Start Docker and wait for its engine.
  2. Drag Invora.app to Applications. Open it from Applications.
  3. Select Start shop. The first build downloads dependencies and takes several minutes. Your browser opens when the shop is ready.
  4. For a new shop, open /setup. Choose Application folder, press Shift–Command–. to show hidden files, and read INVORA_BOOTSTRAP_KEY in the private .env. Create your owner login and password. There is no default password. Existing shops keep their login.
  5. For a commercial release, activate the vendor’s signed licence under Shop licence. The setup key and licence key are different.
About this build: the launcher has an ad-hoc signature for local integrity checking. It is not signed with an Apple Developer ID or notarized. Review the vendor and file checksum before opening. Apple documents the per-app approval under Privacy & Security → Open Anyway. A public commercial release should be signed and notarized by the vendor.

Daily use

Start Docker Desktop and open Invora. Use Start shop to start/open billing, Check status for diagnostics, and Stop shop to stop services while keeping records. Closing the launcher leaves the shop running. The Mac must stay awake while billing.

Updates and records

Take a database-and-uploads backup before an update. Replace the app in Applications, then choose Update release…. The launcher reuses the existing installation and preserves .env and Docker volumes.

New installs use ~/Library/Application Support/Invora for application files and private configuration. Records live in Docker’s invora_database volume, and uploads in invora_documents. Copying the app does not copy shop records. Do not reset Docker or delete these volumes.

The installation includes docs/macos-installation.md and docs/data-storage-security.md, with backup and recovery details. Keep FileVault enabled and maintain tested backups off this Mac.
